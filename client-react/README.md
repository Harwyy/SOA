# client-app

React-клиент для двух REST-сервисов лабораторной работы. Проект перенесён из
клиента лабораторной работы №1 и адаптирован под текущие HTTPS API.

## Возможности

- создание, редактирование и удаление городов;
- получение города по ID;
- фильтрация и поиск названия с начала строки;
- сортировка по нескольким полям;
- пагинация;
- удаление по высоте и дате основания;
- расчёт среднего значения высоты;
- расчёт обоих маршрутов;
- отображение ошибок сервисов с HTTP-кодом и деталями.

Все даты в интерфейсе отображаются как `гггг-мм-дд чч:мм`.

## Запуск

```powershell
npm ci
npm run dev
```

Откройте `http://localhost:5500`.

## Адреса API

По умолчанию Vite выполняет запросы через локальный прокси:

```properties
VITE_CITY_API_URL=/api/city
VITE_ROUTE_API_URL=/api/route
```

Прокси соединяется с Payara на `https://localhost:8181/city-service` и с
WildFly на `https://localhost:8443/route-service`. Поэтому браузеру не нужно
самостоятельно принимать самоподписанные сертификаты.

## Production-сборка

```powershell
npm run build
```

Результат находится в `dist`. Каталог создаётся сборкой и не хранится в исходном проекте.
